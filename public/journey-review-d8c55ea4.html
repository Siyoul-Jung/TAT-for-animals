Function & design check

Walk through it as a visitor would

Go through the site the way a real customer would — arriving for the first time, signing up, paying, then finding their way around the account and library. At each step, check that it both works and looks and feels right, and flag anything that confuses you, looks off, or doesn’t behave.

Nothing here can cost real money. Stripe is in test mode, so the checkout step uses a test card (given below) and never charges anything.

Each item has a quick Good / Found an issue toggle and a notes box. Be as blunt and technical as you like — broken links, layout that breaks at a certain width, a flow that dead-ends, a console error, a wrong price, anything that reads as off-brand. The more specific (which page, which width, what you did), the faster I can fix it.

Heads-up: the video library isn’t populated yet, so it’ll look sparse — we’re only checking the shell and the access rules for now.

What we were going for — a quick frame for your eye:

The site leans simple, warm and human — never slick or “AI-looking,” one clear purpose per screen, clean and uncluttered. If anything pulls against that — a screen that feels busy, cold, or off-brand — it’s worth flagging.

1 · The core member journey

The path a new member actually takes. Start logged out, in a fresh browser if you can.

Sign up

Create an account and confirm the email

Do

From the home page, find the way to join and sign up with a real email you can open. Then confirm via the email we send.

Use a fresh email for this — not hello@tatforanimals.com, which is already registered (it would just bounce you to “already in use”). A personal address works, or hello+test@tatforanimals.com, which lands in the same inbox but counts as a brand-new sign-up.

Sign-up form behaves (validation, errors)? Confirmation email arrives, renders correctly, link works and lands in the right place? Try the resend path too.

Account

The dashboard

3 · Supporting flows

The flows a member hits less often, but that have to work.

Forgot & reset password

From sign-in, run “forgot password” → reset email → set a new password → sign in with it. Whole loop holds?

Manage / cancel subscription

From the dashboard, go into manage and try a cancel (test mode). Does it work, confirm clearly, and feel pressure-free? Re-subscribe after if you want to reset.

Upgrade Basic → Pro

As a Calm Library (basic) member, find the upgrade to Calm Circle — on the dashboard or the Live Sessions card — and go through it (test mode). Does it move you to Pro, show the right pro-rata difference, and unlock the Pro-only Live content afterwards? (If you joined on Pro, cancel and re-join on basic to test this.)

Delete account

From the account page (cancel any subscription first), request deletion. You should get a confirm step before anything happens, then an email with a link — try the “send again” option too. Does the whole loop hold, read clearly, and feel calm rather than alarming?

4 · Across the board

The cross-cutting checks — the things that don’t belong to one page.

Responsive — phone, tablet, desktop

Resize / use real devices. Anything that clips, overflows, overlaps, or gets cramped at a particular width? Buttons big enough to tap?

A second browser

Try a different browser (Safari / Chrome / Firefox / Edge). Anything render or behave differently?

Links, footer & legal pages

Footer links, social icons, and the Privacy / Terms / Disclaimer pages all load. No dead links, no placeholder text left in.

Anything off-brand or visually off

A practised eye for the things a visitor wouldn’t name: misalignment, inconsistent spacing, an odd colour, a font that looks wrong, something that feels cheap or “not us.”

5 · Anything else

Anything that didn’t fit above — a console error you noticed, a slow page, a hunch, an idea. All of it helps.
